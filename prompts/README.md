# 教材の作り方（教材づくりプロンプト）

Paper Reader Hub には教材が入っていません。読みたい論文の章を、**自分の AI に「章のデータファイル」にしてもらい**、アプリに取り込んで使います。
そのための指示文（プロンプト）が [`paper-reader-prompt.md`](paper-reader-prompt.md) です。

## 用意するもの

- 論文の PDF（自分が読む権利を持っているもの）
- ファイルを読めて、ファイルを作れる AI。おすすめは **claude.ai の「プロジェクト」**（PDF を添付でき、長い指示を覚えておける）。
  訳と解説の質は AI のモデルで大きく変わるので、**使える中でいちばん上位のモデル**を選んでください。

## 最初に1回だけ: プロジェクトを作る（claude.ai の場合）

1. claude.ai で「プロジェクト」→「新しいプロジェクト」を作る（名前は「論文リーダー」など）
2. プロジェクトの「指示」（カスタム指示）に、[`paper-reader-prompt.md`](paper-reader-prompt.md) の**全文**を貼り付ける
   - 「0. 目的と、やらないこと」の**読み手**の段落は、自分の英語の力や目的に合わせて書き換えてかまいません
   - ファイルを開いて右上の「Copy raw file」ボタンで、全文をコピーできます
3. 設定で「ファイルの作成」（コード実行）を使えるようにしておくと、章のデータファイルをファイルとして受け取れます

## 章を作ってもらう

1. プロジェクトで新しいチャットを開き、論文の PDF を添付して「II-A をお願いします」のように頼む
   - 章が長いときは、分け方を聞かれます
   - 同じ論文の2章目からは、前にもらった**全体図の `.json`** も添付するか、プロジェクトのファイルに入れておく
2. 章のデータファイル（`<章ID>.txt`）と、必要なら全体図（`<資料ID>-overview.json`）が届く
3. アプリの「教材」→「ファイルを選ぶ」で、2つをまとめて選ぶ
   - ファイルで受け取れなかったときは、コードブロックの中身をコピーして「文字を貼り付けて取り込む」に貼る（全体図を先に）
4. アプリが形を点検します。直す所があると取り込まないので、「直す所をコピー」を押して同じチャットに貼ると、直したファイルをもらえます

1つのチャットで作るのは1〜2章までにしてください（長い会話は遅くなり、使える量も早く減ります）。

## 試しに見てみる

アプリの「教材」→「見本で試す」で、見本の章（このアプリのために書いた英文）を取り込めます。
見本のファイルは [`hub/samples/demo-unit.txt`](../hub/samples/demo-unit.txt) と [`hub/samples/demo-overview.json`](../hub/samples/demo-overview.json) です。プロンプトが作るファイルの形の見本にもなります。

## 気をつけること

- 作った章のデータファイルには論文の本文が入っています。**自分で使うだけ**にして、公開しないでください（論文の著作権のため）。
- アプリの点検は**形の誤り**（書き方の崩れ、必要な項目が無い、など）だけを見つけます。訳や解説の意味の誤りは見つけません。
- Gemini や ChatGPT でも同じプロンプトで作れますが、試しているのは Claude だけです。

## 書式の詳しい決まり

章のデータファイルの書式は [`paper-reader-prompt.md`](paper-reader-prompt.md) の「5. 章のデータファイル」、全体図は「6. 全体図」にあります。
アプリの中でこれを組み立て・点検しているのは [`hub/import.js`](../hub/import.js) です。
