## 第3条　記録の保存と個人情報

1. 教材と学習の記録は、利用者の端末のブラウザの中（IndexedDB）にだけ保存されます。作者のサーバーはなく、作者がこれらを受け取ったり、見たり、集めたりすることはありません。
2. このアプリは、アクセス解析、広告、Cookie による追跡を使っていません。作者が利用者の個人情報を取得することはありません。
3. ただし、このアプリを開くと、公開に使っている GitHub Pages（GitHub, Inc.）と、文字の表示に使っている Google Fonts（Google LLC）に、ふつうのウェブサイトを開いたときと同じくアクセスの情報（IP アドレスやブラウザの種類など）が届きます。これらの扱いは、各社のプライバシーポリシーに従います。
4. 記録は端末の中にしかないため、次のようなときは消えて、元に戻せなくなります。
   - ブラウザの設定などで、サイトのデータを消したとき
   - 端末をなくした、壊れた、初期化したとき
   - iPhone の Safari で、長いあいだアプリを開かなかったとき（ホーム画面に追加して使うと起きにくくなります）
   - アプリの URL が変わったとき（記録は URL ごとに分かれて保存されるため）
5. 利用者は、「保存」→「バックアップを書き出す」で、ときどき記録をファイルにしておいてください。バックアップのファイルの管理は、利用者の責任で行ってください。
