# 利用規約と注意事項

Paper Reader Hub（以下「このアプリ」）を使う前に読んでください。
このアプリを使った時点で、ここに書いたことに同意したものとします。

最終更新: 2026年11月28日

## このアプリについて

このアプリは、英語の論文を読む練習のために個人が作った、無料の学習用ツールです。
会社やサービスとして運営しているものではありません。できるだけ正しく動くように作っていますが、
動作や内容を保証することはできません。

## 記録の保存について

教材と学習の記録は、あなたの端末のブラウザの中（IndexedDB）にだけ保存されます。
作者のサーバーはなく、作者があなたの記録を見たり集めたりすることはありません。アクセス解析や広告も入れていません。

そのぶん、記録を守れるのはあなた自身だけです。次のようなときは、記録が消えて元に戻せなくなります。

- ブラウザの「閲覧データを消去」などで、サイトのデータを消したとき
- 端末をなくした、壊れた、初期化したとき
- iPhone の Safari で、長いあいだアプリを開かなかったとき（ホーム画面に追加して使うと起きにくくなります）
- アプリの URL が変わったとき（記録は URL ごとに分かれて保存されるため）

大事な記録は、「保存」→「バックアップを書き出す」でときどきファイルにしておいてください。
記録が消えたことで生じた損害について、作者は責任を負いません。

## 外部のサービスについて

このアプリは GitHub Pages で公開しています。アプリを開くと、GitHub と、文字の表示に使っている Google Fonts に、
通常のウェブサイトと同じようにアクセスの情報（IP アドレスなど）が届きます。これらの扱いは、それぞれの会社のプライバシーポリシーに従います。

書くタブの添削や、教材づくりで使う AI（Claude、Gemini、ChatGPT など）は、あなたが自分のアカウントで使う外部のサービスです。
貼り付けた文章はそのサービスに送られます。各サービスの利用規約を守って使ってください。
作者はそれらのサービスと関係がなく、内容や動作に責任を持つことはできません。

## 教材と著作権について

このアプリには教材が入っていません。教材は、あなたが自分の AI で作って取り込むものです。

論文や教科書の文章には著作権があります。教材のファイル（章のデータファイルや全体図）と、それを含むバックアップには
原文と訳が入っているので、**自分の学習のためだけに使い、インターネットに公開したり人に配ったりしないでください**。
論文の PDF も、あなたが読む権利を持っているものだけを使ってください。

AI が作った訳・構文解説・単語の意味には、まちがいが含まれることがあります。
アプリが取り込むときに点検するのは書式だけで、内容が正しいかどうかは確かめていません。
大事なところは、原文や辞書で確かめるようにしてください。

## してほしくないこと

- 他人の著作物を含む教材を、このアプリやそのファイルを通じて公開・配布すること
- このアプリを、作者が作った公式のサービスであるかのように見せて配ること
- アプリを公開している GitHub に、不正なアクセスや過剰な負荷をかけること

## 免責

このアプリは「そのまま」の状態で提供しています。このアプリを使ったこと、または使えなかったことによって生じた
損害（記録の消失、学習の成果、外部サービスとのやりとりを含みます）について、作者は責任を負いません。

## 変更と終了

この規約やアプリの内容は、予告なく変えることがあります。大きく変えるときは、このページの最終更新日を改めます。
アプリの公開は、作者の判断で終えることがあります。終える場合も、端末の中の記録はバックアップとして書き出せます。
