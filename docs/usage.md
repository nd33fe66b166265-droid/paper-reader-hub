# 使い方

アプリ: **https://maitona.github.io/paper-reader-hub/**　・　[利用規約と注意事項](terms.md)

スマホでもパソコンでも、ブラウザで開くだけで使えます。登録やログインはありません。
教材と学習の記録は**その端末のブラウザの中だけ**に保存され、どこにも送られません。

## 1. はじめに

### ホーム画面に追加する（スマホ）

ブラウザのタブのままでも使えますが、ホーム画面に追加すると、アプリのように開けて、通信できない所でも使えます。
保存した記録も消されにくくなります。

- **Android（Chrome）**: 今日の画面の「ホーム画面に追加できます」→「方法を見る」、またはメニュー（︙）→「ホーム画面に追加」
- **iPhone（Safari）**: 共有ボタン → 「ホーム画面に追加」 → 「追加」

iPhone では、Safari とホーム画面のアプリは記録を別々に持ちます。ホーム画面に追加してから使い始めるのがおすすめです。

### 見本で試す

「教材」→「見本で試す」→「取り込む」で、見本の章（3 段落）が入ります。読む・復習・書くを一通り試せます。
試し終わったら、「教材」の一覧から「削除」で消せます。

## 2. 教材を入れる

教材は、自分の AI（おすすめは claude.ai のプロジェクト）に論文の章を「章のデータファイル」にしてもらって取り込みます。
準備と頼み方は [prompts/README.md](../prompts/README.md) にあります。

1. AI から `<章ID>.txt`（と、新しい論文なら `<資料ID>-overview.json`）を受け取る
2. 「教材」→「ファイルを選ぶ」で、まとめて選ぶ（ファイルにできなかったときは「文字を貼り付けて取り込む」）
3. 点検の結果を見て「取り込む」
   - **直す所**があるときは取り込みません。「直す所をコピー」を押して AI に貼ると、直したファイルがもらえます
   - **気になる所**は、取り込めるけれど確かめた方がよい所です
4. 「読む」を押すと、その章が開きます

同じ章ID のファイルをもう一度取り込むと**差し替え**になります。覚えた単語と表現の記録はそのまま引き継がれます。

## 3. 毎日の使い方

| 画面 | すること |
|---|---|
| **今日** | 今日の復習の枚数、学習時間（自動で計り、手でも記録できる）、学習の記録のグラフ、資料と章の一覧 |
| **復習** | 単語（英→日）、熟語・定型文（日→英）、書くタブの添削カードを、間隔をあけてくり返す。「忘れた／あいまい／覚えた」で次に出る日が決まる。カードの下に、その語が出てきた元の文が出る |
| **単語帳** | 取り込んだ章の単語と熟語の一覧。検索・章・状態で絞り込める |
| **読む** | 英文を読み、必要なときだけ「訳」「構文解説」「英単語」を開く。下線の語はタップで意味が出る。「音読」では読み上げとシャドーイング |
| **書く** | 読んだ章を英語で要約し、AI に添削してもらう（下の 4.） |

- 復習を1枚もしなかった日は、その後の復習日が1日ずつずれます（次の日に2日分たまりません）。1日の区切りは午前4時です
- 「今日は新出を休む」をオンにすると、その日は新しい単語・表現を出さず、復習だけにできます
- 1日の新出の数、復習の上限、色のモード、読み上げの声などは「設定」で変えられます

## 4. 書くタブの添削（自分の AI との往復）

アプリは AI に直接つながりません。添削は「コピー → 貼り付け」で自分の AI に頼みます。

1. 章を選び、英語で要約を書いて「添削する」
2. 頼む先（Claude・Gemini・ChatGPT）を選び、「依頼文をコピー」
3. その AI で新しいチャットを開いて貼り付け、送る
4. 返事のコードブロック（`{` で始まる枠）をコピーして、アプリに貼る

直した英文とその訳が出て、間違えた所は「添削カード」として復習に加えられます。
返事の形が崩れていたときは、アプリがどこがおかしいかを知らせます。

## 5. バックアップ（大事）

記録は端末のブラウザの中にしかありません。**ブラウザのデータを消す・端末をなくす・アプリの URL が変わる**と、そのままでは戻せません。
ときどき「保存」→「バックアップを書き出す」で、1つのファイル（`.hubbackup.json`）にしておいてください（14 日たつと今日の画面でおすすめします）。

- ファイルは端末の外（Google ドライブ、iCloud Drive など）にも置くと安心です
- 戻すときは「保存」→「バックアップを読み込む」
- 読み込む前の状態は取っておくので、間違えたときは「戻す前の状態に戻す」で戻せます

## 6. パソコンとスマホの両方で使う

記録は端末ごとに別々です。2台をそろえるときは:

1. 片方で「バックアップを書き出す」
2. もう片方で「バックアップを読み込む」→「**合わせる**（おすすめ）」
3. 逆向きにも同じことをすると、2台が同じになります

合わせると、同じカードは最後に学習した方が残り、学習時間は2台の分が合わさります。
「置き換える」を選ぶと、読み込んだファイルの中身だけになります。決まりの詳しいことは [backup-format.md](backup-format.md) にあります。

## 7. 困ったとき

| こんなとき | すること |
|---|---|
| 表示がおかしい・新しい版にならない | 「保存」→「開き直す」（記録は消えません） |
| 取り込めない | 「直す所をコピー」を AI に貼って、直したファイルをもらう |
| 記録が消えた | バックアップがあれば「バックアップを読み込む」。ブラウザが違う（Safari とホーム画面のアプリなど）だけのこともあります |
| 通信できない所で使いたい | 一度通信できる所で開いておけば、ホーム画面のアプリから開けます |
